# JBLWaveBeam

אפליקציית מגש מערכת (System Tray) ל-Windows לשליטה ובקרה על אוזניות **JBL Wave Beam** (דור ראשון) ישירות דרך Bluetooth, מבוססת על פרויקט הקוד הפתוח **OpenHeadphones** (Rust) ללא צורך ב-WebView ובתוספת התאמות ייעודיות לסביבת Windows.

## מה התוכנה עושה?
- **חלונית מהירה ליד השעון:** תצוגת אחוזי סוללה, מצבי ביטול רעשים / שמע סביבתי (ANC / Ambient) ואקוולייזר (EQ).
- **קובץ יחיד ללא התקנה:** נבנית כקובץ `JBL-Wave-Beam.exe` עצמאי (ללא צורך בתיקיות נלוות).
- **ללא חיבור לרשת:** בדיקת העדכונים האוטומטית מהמאגר המקורי הוסרה מהקוד.

- **[README-upstream-OpenHeadphones.md](./README-upstream-OpenHeadphones.md)** — תיעוד הפרויקט המקורי (OpenHeadphones).

## דגלי שורת פקודה שימושיים
- `--open` — פתיחת החלונית מיד עם ההפעלה.
- `--pinned` — השארת החלונית פתוחה גם בעת איבוד פוקוס.
- `--debug` — רישום חבילות ה-Bluetooth הנשלחות והמתקבלות לצורכי אבחון.
